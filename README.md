## 🚀 Projetos em destaque

### ValveGuard

Monitor de recursos do sistema Linux desenvolvido em C.

O projeto utiliza arquivos do diretório `/proc` para exibir informações como CPU, memória RAM e uptime diretamente no terminal.

Principais aprendizados:

* Programação em C
* Leitura de arquivos do sistema Linux
* Uso de terminal
* Manipulação de strings
* Organização inicial de um projeto técnico
* Entendimento básico de métricas do sistema
